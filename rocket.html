Project Overview

As part of UBC Rocket's avionics team, I have worked on microcontroller firmware and board-level engineering tasks that connect embedded software with physical hardware.

Technical Contributions

  • STM32 firmware: Developed and debugged embedded C code for microcontroller-based functionality.
  • Communication: Configured and worked with SPI and UART peripheral interfaces.
  • Digital I/O: Worked with GPIO and interrupt-driven functionality.
  • Hardware: Contributed to PCB development and hardware verification activities.
  • Debugging: Used engineering tools to investigate hardware-software integration issues.

Engineering Approach

My work emphasizes understanding the full signal path: from firmware configuration and peripheral behavior to physical interfaces and board-level testing. I aim to isolate problems methodically and validate changes using observable hardware behavior.

Skills Developed

Embedded C development, STM32 peripheral configuration, serial communication, board-level testing, and cross-disciplinary collaboration within a student engineering design team.
