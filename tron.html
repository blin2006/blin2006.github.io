Real-Time Tron
Light Cycle Game

A two-player arcade-style game implemented in C on an FPGA platform, combining memory-mapped VGA graphics, hardware timer interrupts, and collision detection.

CFPGAVGATimer InterruptsMemory-Mapped I/O

Project Overview

This project implements a real-time, two-player Tron-style game on an FPGA-based platform. Players navigate across a display, leaving trails while avoiding collisions. The project connects low-level C programming with hardware interfaces and real-time game behavior.

System Design

  • Display: Memory-mapped VGA graphics for rendering the playfield and moving player trails.
  • Timing: Hardware timer interrupts to coordinate periodic game updates.
  • Game logic: Player movement, trail tracking, and collision detection.
  • Debugging: Investigating timing, memory access, and game-state behavior.

Engineering Challenges

Building an interactive game on embedded hardware requires careful coordination between display writes, player input, and periodic updates. The development process involved debugging the interaction between software logic and hardware timing.

What I Learned

Practical experience with memory-mapped hardware interfaces, interrupt-driven programming, framebuffer-style rendering, and systematic debugging on an FPGA platform.
